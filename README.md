## ?? Getting Started

### For End Users
1. Read **USER_GUIDE.md** - Start here for usage instructions
2. Contact support for credentials
3. Follow "Getting Started" section in USER_GUIDE
4. Submit your first claim

### For Developers
1. Read **DEVELOPER_GUIDE.md** - Architecture and setup
2. Clone the repository: `git clone https://github.com/sibtaincs/NPhies_FHIR_Integration.git`
3. Follow installation instructions
4. Run locally: `dotnet run --project NPhies_FHIR_Integration.ApiService`
5. Access Swagger UI: https://localhost:5001/swagger
