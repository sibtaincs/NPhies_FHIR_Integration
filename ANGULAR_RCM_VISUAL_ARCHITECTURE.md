## 6?? **HTTP REQUEST INTERCEPTOR CHAIN**

```

        ?

    HTTP Interceptor 1: JwtInterceptor

    ?? Add "Authorization: Bearer <token>" header
    ?? Pass to next interceptor
        ?
 ?
    HTTP Interceptor 2: ErrorInterceptor
    ?? Let request pass through
    ?? On response:
        ?? If 401: Logout user, redirect to login
        ?? If 403: Show permission denied
      ?? If 500: Show server error
        ?? If other error: Show error message
        ?
        ?

  ?? Add Accept: application/json
    ?? Add Content-Type: application/json
    ?? Send HTTP request to backend
        ?
        ?
    .NET 9 Backend (Receives request)
    ?
     ?

        ?
 ?
    HTTP Client (Receives response)
        ?
        ?
    HTTP Interceptor 2: ErrorInterceptor
    ?? Check response status
    ?? If error: Handle and show message

        ?
```

## ? **KEY DESIGN CONCEPTS**

1. **Unidirectional Data Flow**: Data flows down, events flow up
2. **Reactive Programming**: Observables for async operations
3. **Dependency Injection**: Services injected into components
4. **Separation of Concerns**: Each layer has specific responsibility
5. **Security**: JWT tokens and interceptors
6. **Type Safety**: TypeScript interfaces
7. **Scalability**: Modular feature modules
8. **Performance**: Lazy loading, OnPush detection
9. **Error Handling**: Global interceptor
10. **Testability**: Mockable services
