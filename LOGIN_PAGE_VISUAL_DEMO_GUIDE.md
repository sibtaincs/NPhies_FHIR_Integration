## ?? **USER INTERACTION FLOWS**

### **Flow 1: Successful Login**

```
1. User navigates to /auth/login
   ?? Page loads with animation

2. Form displays
   ?? Username/password fields visible

3. User enters credentials
   ?? Real-time validation

4. User clicks "Sign In"
   ?? Form validation runs
   ?? If valid ? Loading spinner shows
   ?? If invalid ? Error messages appear

5. API request sent
   ?? POST /api/auth/login
   ?? Loading state active (1-2 seconds)

6. Response received
   ?? Tokens stored in localStorage
   ?? Success message displays
   ?? Auto-redirect to /dashboard (1 second)

7. Dashboard loads
   ?? User authenticated
   ?? Role-based content visible
```

### **Flow 2: Failed Login**

```
1. User enters wrong credentials

2. Clicks "Sign In"

3. Validation passes (form structure is valid)

4. API request sent

5. Server returns error
   ?? 401 Unauthorized or similar

6. Error alert displays
   ?? "Invalid username or password"
   ?? Red background
   ?? Closeable with X

7. Form remains visible

8. User can:
   ?? Correct credentials
   ?? Click "Forgot password?"
   ?? Click demo button for testing
```

### **Flow 3: Using Demo Credentials**

```
1. User sees "DEMO CREDENTIALS" section

2. Clicks [Reviewer] or [Manager] button

3. Form auto-fills:
   ?? Username: john.reviewer / admin.manager
   ?? Password: TestPassword123! / AdminPassword123!

4. User clicks "Sign In"

5. Login succeeds (assuming backend allows)

6. Tokens stored & redirect to dashboard
```

### **Flow 4: Forgot Password**

```
1. User clicks "Forgot password?" link

2. Navigates to /auth/forgot-password

3. Enter email or username

4. Receive reset link via email

5. Click link to reset password

6. Return to login page
```
