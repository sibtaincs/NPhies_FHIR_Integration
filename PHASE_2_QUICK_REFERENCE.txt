?? BUSINESS LOGIC EXPLAINED
???????????????????????????????????????????????????????????????????????????

Example Scenario:
   Insurance Plan:
      - Annual Deductible: $500
      - Coinsurance: 20% (patient pays 20%, insurance pays 80%)
      - Out-of-Pocket Max: $5,000
      
   Patient Status:
      - Deductible Met: $0 (just starting)
      - Out-of-Pocket Met: $0
      
   Claim Item:
      - Submitted: $1,000
      - Allowed: $800
      - Not Allowed: $200 (patient pays)
      
   Calculation:
1. Apply Deductible: 
         - Deductible Applied: $500 (meets full deductible)
         - Remaining: $300 after deductible
      
      2. Apply Coinsurance:
- 20% of $300 = $60 (patient)
         - 80% of $300 = $240 (insurance)
    
      3. Apply Out-of-Pocket:
   - Patient OOP: $500 (deductible) + $60 (coinsurance) = $560
         - Total OOP Met: $560
  - OOP Remaining: $4,440
      
   Final Result:
    - Insurance Pays: $240 + $200 (not allowed doesn't apply) = $240
      - Patient Pays: $500 + $60 + $200 = $760


?? HOW TO USE
???????????????????????????????????????????????????????????????????????????

1. Inject the Service:
   ```csharp
   [HttpPost("calculate-benefit")]
   public async Task<IActionResult> CalculateBenefit(
       [FromBody] CalculationRequest request,
    [FromServices] IPaymentCalculationEngine engine)
   {
       var items = request.ClaimItems
           .Select(i => new ClaimItemBenefitContext 
           { 
   ItemSequence = i.Sequence,
         SubmittedAmount = i.Amount,
      AllowedAmount = i.AllowedAmount
           })
           .ToList();
     
       var config = new BenefitConfiguration
       {
        AnnualDeductible = coverage.AnnualDeductible,
   DeductibleMet = coverage.DeductibleMet,
           CoinsurancePercent = 20,
           OutOfPocketMax = coverage.OutOfPocketMax,
           OutOfPocketMet = coverage.OutOfPocketMet
     };
       
       var result = engine.CalculateClaimBenefit(items, config);
       return Ok(result);
   }
   ```

2. Get Results:
   - `result.TotalAllowedAmount` - Total covered
   - `result.TotalInsuranceResponsibility` - Insurance pays
   - `result.TotalPatientResponsibility` - Patient pays
   - `result.ItemCalculations` - Per-item detail
   - `result.ValidationErrors` - Any issues
