PERFORMANCE OPTIMIZATION TIPS
????????????????????????????????????????????????????????????????????????

1. CACHING
```csharp
// Cache master data for 24 hours
services.AddScoped<IMasterDataCache, MasterDataCache>();

// Usage:
var service = await masterDataCache.GetServiceCodeAsync(
    "SRV001", 
    cacheTimespan: TimeSpan.FromHours(24)
);
```

2. INDEXING
- Index all code columns (ServiceCode, MedicationCode, etc.)
- Index all foreign keys
- Index all frequently searched columns (PayerId, PolicyCode, etc.)

3. BATCH OPERATIONS
```csharp
// Load multiple at once instead of one-by-one
var services = await masterDataRepo.GetServicesByCodesAsync(
    new[] { "SRV001", "SRV002", "SRV003" }
);  // Single DB query instead of 3
```

4. LAZY LOADING CAUTION
```csharp
// ? AVOID: Causes N+1 queries
var policies = await dbContext.PayerPolicies.ToListAsync();
foreach (var policy in policies) {
    var payer = policy.Payer.PayerName;  // Extra query!
}

// ? USE: Include related data
var policies = await dbContext.PayerPolicies
  .Include(p => p.Payer)
    .ToListAsync();
