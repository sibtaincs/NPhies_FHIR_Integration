## ?? Quick Start Commands

```bash
# 1. Clone repository
git clone https://github.com/sibtaincs/NPhies_FHIR_Integration
cd NPhies_FHIR_Integration

# 2. Restore packages
dotnet restore

# 3. Update configuration
# Edit NPhies_FHIR_Integration.ApiService/appsettings.json

# 4. Run database migrations
dotnet ef database update --project NPhies_FHIR_Integration.Infrastructure

# 5. Run application
dotnet run --project NPhies_FHIR_Integration.ApiService

# 6. Test diagnostics
curl https://localhost:5001/api/NphiesDiagnostics/full

# 7. Test eligibility (replace with real data)
curl -X POST https://localhost:5001/api/eligibility/check \
  -H "Content-Type: application/json" \
  -d '{
    "patientId": "PAT-123",
    "coverageId": "COV-456",
    "providerId": "ORG-789",
    "insurerId": "ORG-012"
  }'
```
