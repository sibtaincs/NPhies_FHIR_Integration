1. PROVIDER SENDS POLL REQUEST TO NPHIES
   ?? POST /api/v1/polling/request
 ?? Creates TaskRequest with "poll" code

2. PROVIDER RECEIVES POLL RESPONSE FROM NPHIES
   ?? POST /api/v1/polling/response
   ?? Contains Task with output Bundle
   ?? Output Bundle contains multiple queued messages
   ?? Processing extracts:
      ?? MessageHeaders
      ?? ClaimResponses
      ?? CoverageEligibilityResponses
      ?? Communications
      ?? Nested Bundles (claim-response, etc.)

3. PROVIDER RETRIEVES QUEUED MESSAGES
   ?? GET /api/v1/polling/messages/{providerId}
   ?? Returns all messages waiting for provider

4. PROVIDER ACKNOWLEDGES PROCESSING
   ?? PUT /api/v1/polling/responses/{taskResponseId}/acknowledge
   ?? Marks response as "acknowledged"

TaskRequest (Poll Request)
??????????????????????????
? Id: Unique identifier
? TaskId: FHIR Task ID (format: poll-xxxxxxxx)
? Status: "requested", "in-progress", "completed"
? Code: "poll" (identifies as polling request)
? RequesterId: Provider organization ID
? OwnerId: "NPHIES" (the system)
? ProcessingStatus: "pending", "sent", "received"
? CreatedAt: Timestamp

Example:
{
  "id": "uuid-1",
  "taskId": "poll-abc12345",
  "status": "requested",
  "code": "poll",
  "requesterId": "provider-org-123",
  "ownerId": "NPHIES",
  "processingStatus": "pending",
  "createdAt": "2024-12-03T10:00:00Z"
}

????????????????????????????
? Id: Unique identifier
? TaskId: FHIR Task ID from NPHIES

? RequesterId: Provider organization ID
