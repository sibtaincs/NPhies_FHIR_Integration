The polling service can extract and process the following FHIR resources
from poll response bundles:

1. MessageHeader
   ?? Contains message metadata and routing information
   ?? Parsed fields: id, eventCode, sender, receiver

2. ClaimResponse
   ?? Insurance company's response to submitted claim
   ?? Parsed fields: id, status, outcome, adjudications
   ?? Status: Ready (TODO: Store in database)

3. CoverageEligibilityResponse
   ?? Response to eligibility check request
   ?? Parsed fields: id, status, benefits, coverage
   ?? Status: Ready (TODO: Store in database)

4. Communication
   ?? Direct message between provider and insurer
   ?? Parsed fields: id, status, content, attachments
   ?? Status: Ready (TODO: Store in database)

5. Bundle (Nested)
   ?? Contains another message bundle
   ?? Example: claim-response-bundle nested in poll-response-bundle
   ?? Parsed fields: id, type, entries
   ?? Status: Ready (TODO: Store bundle metadata)
